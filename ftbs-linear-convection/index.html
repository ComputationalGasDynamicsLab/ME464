Why c ≤ 1? The stencil

The dashed line is the characteristic. The true value at the new time comes from where it lands at time level n. The scheme only uses points i−1 and i, so that landing point has to fall between them, which means c ≤ 1.

c < 1: numerical diffusion

Rewrite the update as uin+1 = (1−c) uin + c ui−1n. Each new value is a weighted average of two neighbors. Averaging rounds off sharp corners, so the shock front smears into a ramp. A smaller c needs more steps to reach the same time, so it smears more.

c = 1: exact shift

The update becomes uin+1 = ui−1n. Each step copies every value one cell to the right. That is exactly what the PDE does in one Δt, so the error stays at zero.

c > 1: unstable

The weight 1−c turns negative, so the update is no longer an average. Small wiggles get amplified every step, and the solution grows without bound. This is the CFL condition in action.
