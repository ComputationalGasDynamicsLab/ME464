Parameters

k = N/2 is the sawtooth (θ = π, two points per wavelength). Small k is a long wave. Here δ is advanced on its own, so it stays one pure mode; with random noise, round-off always contains the sawtooth too.

Amplification factor G(θ)

As θ goes from −π to π, G traces a circle with center 1 − c and radius c. Stable means the circle stays inside the unit circle.

Unit circle |G| = 1 G(θ), stable G(θ), unstable

Why FTBS needs 0 ≤ c ≤ 1

Von Neumann analysis follows one Fourier mode of the error through one time step. The scheme is linear, so every mode evolves on its own, and any error is a sum of modes. This page runs on a periodic grid so that the boundaries do not interfere. Back to the convection lab.

The amplification factor

Put δjn = Gn eijθ into the FTBS update. Every term shares the factor Gn eijθ, which cancels and leaves

G = 1 − c + c e−iθ,   |G|² = 1 − 2c(1 − c)(1 − cos θ)

A mode is multiplied by G every step. The scheme is stable if |G| ≤ 1 for every θ. Since 1 − cos θ ≥ 0, this holds exactly when c(1 − c) ≥ 0, that is 0 ≤ c ≤ 1.

The worst mode is the sawtooth

The largest |G| is at θ = π, the shortest wave the grid can hold (+, −, +, − at neighboring points). There G = 1 − 2c. For c = 1.1 it is −1.2: the sawtooth flips sign and grows 20% every step. Choose the single-mode perturbation and move k to see that long waves grow much more slowly.

Round-off seeds every mode

Every floating-point operation has a relative error of about 10−16. These errors contain all wavelengths, including the sawtooth. For c ≤ 1 they stay at round-off level. For c > 1 the sawtooth part grows like 10−16·|1 − 2c|n until it swamps the solution.

An instability can hide

Starting from 10−16, reaching size 1 takes n ≈ ln(1016)/ln|1 − 2c| steps: about 200 at c = 1.1 and 390 at c = 1.05. A short run can look fine. In the convection lab, the step in the initial condition already contains short waves of size 1, so there the same instability shows up within a few dozen steps.
