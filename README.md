# ME464

Course materials for ME464 from the Computational Gas Dynamics Lab. Each example is in its own folder.

| Example | Interactive page | Folder |
|---|---|---|
| 1D linear convection: numerical diffusion (FTBS), dispersion (Lax–Wendroff) and TVD flux limiters | [Open in browser](https://computationalgasdynamicslab.github.io/ME464/ftbs-linear-convection/) | [`ftbs-linear-convection/`](ftbs-linear-convection/) |
| Sod shock tube: 1D Euler equations with Roe, HLLC, AUSM+ and AUSM+-up fluxes | [Open in browser](https://computationalgasdynamicslab.github.io/ME464/sod-shock-tube/) | [`sod-shock-tube/`](sod-shock-tube/) |
| Sod shock tube with finite differences: Lax–Friedrichs, Lax–Wendroff and MacCormack | [Open in browser](https://computationalgasdynamicslab.github.io/ME464/sod-shock-tube-fd/) | [`sod-shock-tube-fd/`](sod-shock-tube-fd/) |

The interactive pages run in any web browser with nothing to install. To run the Python code on
your own computer, follow the step-by-step instructions in each example's README.
