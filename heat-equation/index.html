Amplification factor per step

Each Fourier mode sin(kx) is multiplied by G every step, with θ = kΔx. The exact decay per step is e−rθ². A scheme is stable when |G| ≤ 1 for every θ (inside the band). Long waves are on the left, the sawtooth (θ = π) on the right.

Explicit vs implicit stencils

Filled: known values at time level n. Open: unknowns at n+1. FTCS gives each new value directly. BTCS and Crank–Nicolson couple neighbors at n+1, so every step solves a tridiagonal system (Thomas algorithm, O(N) work).

Three ways to step in time

All three schemes use the same central difference for ∂²T/∂x². They differ only in the time level at which it is evaluated: the old level (explicit), the new level (implicit), or the average of the two.

FTCS: explicit

Tin+1 = Tin + r (Ti+1n − 2Tin + Ti−1n)

Cheap and simple, error O(Δt) + O(Δx²). Written as rTi−1 + (1−2r)Ti + rTi+1, it is a weighted average of three neighbors as long as 1 − 2r ≥ 0. For r > ½ the middle weight goes negative and the sawtooth grows: G(π) = 1 − 4r < −1.

The modified equation is Tt = αTxx + (αΔx²/12)(1 − 6r)Txxxx + …, so at r = 1/6 the leading error cancels and FTCS becomes fourth order in Δx. Try the "Most accurate" preset.

BTCS: fully implicit

−rTi−1n+1 + (1+2r)Tin+1 − rTi+1n+1 = Tin

G = 1 / (1 + 4r sin²(θ/2)) lies between 0 and 1 for every r, so the scheme is unconditionally stable and never oscillates. The price: a tridiagonal solve per step, and the error is still first order in time, so a large Δt is stable but not accurate. Compare its error with the others.

Crank–Nicolson: the average

Tin+1 − Tin = (r/2)[δ²Tn+1 + δ²Tn]

Second order in both time and space, and unconditionally stable: G = (1 − 2r s)/(1 + 2r s) with s = sin²(θ/2). But for large r the sawtooth gets G ≈ −1, so it is barely damped and flips sign every step. With the square pulse and r = 5 you can see the wiggles that the true heat equation would wipe out at once.
