Tridiagonal matrix algorithm (TDMA)

Thomas Algorithm: Derivation and Demonstration

Solves aixi−1 + bixi + cixi+1 = fi in two passes. Part 0 runs plain Gaussian elimination on a full matrix and then on a tridiagonal one, so you can see what Thomas keeps and what it throws away. Part 1 derives the algorithm in symbols, one row operation at a time. Part 2 runs it on CFD example systems with real numbers.

The wall values move to f; they are not additional unknowns. The entries −r, 1+2r, −r form the three diagonals. In Ax = f, xᵢ is the new temperature Tᵢk+1.

Two passes, two jobs

Forward sweep → 1, 2, …, n

Remove the left neighbor and normalize each row. This prepares c′ and f′; it does not finish all x values.

xᵢ + c′ᵢxᵢ₊₁ = f′ᵢ
Back substitution ← n, …, 2, 1

Start with xₙ = f′ₙ, then recover each xᵢ from the known value to its right.

The prime means modified, not a derivative. c′ᵢ is the remaining right-neighbor coefficient after elimination and normalization. f′ᵢ is the transformed right-hand side. mᵢ is the pivot before normalization.

Notation. The right-hand side of Ax = f is written f throughout this lab, as in the lecture notes. Many textbooks call the same vector d or r; only the name differs.

One matrix, many heat-equation steps

If the mesh, r and boundary-condition types stay fixed, A stays fixed. New old-time temperatures change f. Factor A once, then reuse its pivots and upper coefficients to solve each new right-hand side.

Watch the temperature after each BTCS time step

A complete Thomas solve produces one new temperature profile. Its forward and backward row operations are not separate physical time steps. Start from the initial profile, solve one time step at a time, and inspect any saved figure.

This profile grid is independent of the three-unknown algebra example above. It shares the wall and initial temperatures. N intervals give N + 1 grid nodes and N − 1 unknown interior temperatures. Try N = 40, 100 or 400. Changing N keeps Δt fixed, so equal step numbers represent equal physical times. Increasing N reduces spatial error; reduce Δt too when time error dominates. BTCS is unconditionally stable, but stability does not guarantee accuracy. Changing either control restarts the history.

When can Thomas elimination fail?
Zero pivot ≠ singular system

A nonsingular matrix can need a row exchange. This unpivoted algorithm cannot perform one. Try “Needs pivoting” in the examples.

Small relative pivot ≠ small matrix

A pivot tiny compared with its row can magnify cancellation. Uniformly scaling all coefficients down need not cause a problem. Try “Tiny pivot” and “Scaled warm-up.”

Diagonal dominance is sufficient, not necessary

Strict dominance in every row guarantees nonzero pivots in exact arithmetic. Weak dominance needs additional conditions, such as an irreducible matrix with at least one strict row. Symmetric positive definite tridiagonal matrices are another safe class.

Nonzero pivots alone do not guarantee a small forward error. The scaled residual below checks how well the computed x satisfies the original system; conditioning also matters. General-purpose tridiagonal solvers may use partial pivoting (LAPACK DGTSV).
